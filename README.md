# SWYNEX-Exploratory-Data-Analysis

## Dataset
Cleaned Titanic Dataset from Task 1

## Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- Google Colab

## Key Insights

1. **Gender Impact**: Females had a much higher survival rate (74.2%) compared to males (18.9%).
2. **Class Impact**: 1st class passengers had the highest survival rate (63%), while 3rd class had the lowest (24%).
3. **Overall Survival**: Only 38.4% of passengers survived.
4. **Age Distribution**: Most passengers were between 20–40 years old.
5. **Fare & Survival**: Higher ticket fares were associated with better survival chances.
